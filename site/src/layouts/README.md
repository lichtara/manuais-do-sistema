# Layouts do Acervo e das Ativações

Os layouts Astro fornecem a estrutura comum das páginas e carregam as fontes e os estilos usados por cada experiência.

- [Base](Base.astro) — estrutura compartilhada pelas páginas do Acervo.
- [ActivationShell](ActivationShell.astro) — estrutura da jornada de Ativações, com cabeçalho próprio e acesso ao Acervo.
