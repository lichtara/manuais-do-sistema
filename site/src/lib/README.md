# Biblioteca do site

Esta pasta reúne os módulos que preparam o conteúdo do Acervo e definem os dados usados nas Ativações.

- [acervo.mjs](acervo.mjs) — descobre os documentos da biblioteca, gera o catálogo e resolve relações e links.
- [markdown.mjs](markdown.mjs) — extrai títulos e âncoras e converte os capítulos de Markdown para HTML.
- [ativacoes.ts](ativacoes.ts) — reúne as Chaves, etapas, temas e caminhos de exploração.
