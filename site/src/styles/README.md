# Estilos do Acervo LICHTARA

Esta pasta contém as folhas de estilo que dão forma às páginas de consulta, ao leitor e ao protótipo de Ativações.

- [global.css](global.css) — estilos compartilhados de tipografia, layout e navegação.
- [reader.css](reader.css) — corpo dos capítulos, sumário e elementos de leitura.
- [ativacoes.css](ativacoes.css) — aparência, transições e adaptação da jornada a diferentes telas.
