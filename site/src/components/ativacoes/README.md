# Componentes de Ativações

Estes componentes apresentam as Chaves e a composição visual da jornada no [protótipo de Ativações](../../../ATIVACOES.md).

- [GeometricKey](GeometricKey.astro) — representação geométrica de cada Chave.
- [SensoryStage](SensoryStage.astro) — composição da etapa sensorial em torno da Chave selecionada.
