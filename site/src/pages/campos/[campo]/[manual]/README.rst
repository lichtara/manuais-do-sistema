Páginas de Manual e Capítulo
============================

As rotas desta pasta mostram a lista de capítulos de cada manual e abrem
seus textos no leitor do Acervo.

* `index.astro <index.astro>`__ — índice de capítulos do manual.
* `[capitulo].astro <%5Bcapitulo%5D.astro>`__ — página de leitura, com navegação entre capítulos.
