# Manual de Canalização Técnica

O manual descreve como o projeto propõe comunicar a origem das informações que chama de canalizadas, avaliar sua incorporação e traduzi-las em material que possa orientar o desenvolvimento tecnológico.

## Por onde começar

- [Canalização técnica](01-canalizaca-tecnica.md) — natureza da comunicação no contexto do projeto.
- [Estratégias de validação e implementação](03-estrategias-validacao-implementacao.md) — critérios e etapas propostos.
- [Plano de aplicação prática](04-plano-aplicacao-pratica.md) — proposta de teste para a incorporação de novas informações.
- [Tradução para o desenvolvimento](07-processo-traducao-desenvolvimento.md) — passagem do registro de origem para o trabalho técnico.
